## Overview

The Microsoft integration lets you access files stored in OneDrive directly from Lawdie's chat interface, and supports Azure-based deployments for firms that run infrastructure on Microsoft's cloud.

## What's included

| Service | What Lawdie can do |
|---------|-------------------|
| **OneDrive** | Browse, attach, and retrieve documents from OneDrive in the chat |
| **Azure** | Infrastructure support for self-hosted Lawdie deployments |

## Connecting OneDrive

<Steps>
  <Step title="Open Settings">
    Navigate to **Settings → Integrations** in the Lawdie dashboard.
  </Step>
  <Step title="Click Connect Microsoft">
    Select the Microsoft integration tile and click **Connect**.
  </Step>
  <Step title="Sign in with Microsoft">
    A Microsoft OAuth window will open. Sign in with your Microsoft 365 or personal Microsoft account and grant Lawdie read access to OneDrive.
  </Step>
  <Step title="Confirm">
    You'll be redirected back to Lawdie with OneDrive accessible from the file picker in the chat.
  </Step>
</Steps>

## Using OneDrive files in the chat

Once connected, click the file picker in the chat input and select **OneDrive**. Browse your files and folders, select a document, and it will be attached to your message for analysis by the [Document Analysis](/features/document-analysis) feature.

**Supported file types from OneDrive:**
- Word documents (`.docx`)
- PDFs
- Excel spreadsheets (`.xlsx`) — for structured data extraction
- PowerPoint presentations (`.pptx`)

## Enterprise Microsoft 365

For firms on Microsoft 365 with managed IT environments, Lawdie supports enterprise sign-in and can be configured to work with your organization's security policies. Contact **support@lawdie.co** to discuss your firm's setup.

## Troubleshooting

| Issue | Fix |
|-------|-----|
| OneDrive picker shows empty | Re-authorize and confirm OneDrive access was granted during sign-in |
| Files fail to attach from OneDrive | Check that the file type is supported and under 50MB |
| Sign-in blocked by your organization | Your IT admin may need to approve Lawdie as an allowed app — contact them or reach out to support@lawdie.co |
