## What it does

The trademark search agent queries the USPTO trademark database by keyword to find registered, pending, and abandoned marks. It supports both active and inactive mark searches and verifies results for relevance before returning them.

## Search types

| Type | Description |
|------|-------------|
| `active` | Returns live, registered, and pending marks (default) |
| `inactive` | Returns abandoned, cancelled, and expired marks |

## Example prompts

- *"Search for active trademarks containing the word 'Apex' in the sporting goods category."*
- *"Is 'Verdant Legal' already trademarked?"*
- *"Find all inactive marks for 'Falcon' in class 45 (legal services)."*
- *"Check if any company has trademarked a logo described as a blue shield with a gavel."*

## How results are verified

Raw USPTO results are filtered through a relevance verification step before being returned. This removes unrelated marks that match a keyword but have no meaningful connection to the searched goods or services category.
