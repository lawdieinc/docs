## What it does

The Rule Statement & RERA agent is a legal writing specialist. It takes case law — either from a prior search or cases you paste in — and runs a two-step workflow:

1. **Extract rule statements** — pulls the court's own operative language (not a paraphrase) and scores each case on how well its rule fits your client's facts
2. **Generate RERA** — drafts a Rule Explanation paragraph (synthesizing the rule from top cases) and a Rule Application paragraph (applying the rule to your client's facts)

The output is brief-ready: inline Bluebook citations as hyperlinks, active voice, no hedging language.

## The workflow

```
searchCaseLaw (find relevant cases)
    ↓
getOpinionText (fetch full text if needed)
    ↓
extract_rule_statements (score cases by argument fit)
    ↓
generate_rera (draft RE + RA paragraphs)
```

<Note>
  `extract_rule_statements` must always run before `generate_rera`. The agent handles this automatically.
</Note>

## Tools

### `extract_rule_statements`

For each case provided, this tool extracts:

| Output field | Description |
|---|---|
| `rule_statement` | The court's own language stating the rule — never paraphrased |
| `dispositive_facts` | Key facts the court relied on (2–3 sentences) |
| `argument_fit_score` | 1–10 score of how well this rule fits your client's facts |
| `source` | Whether the rule comes from the majority or a concurrence |
| `recommended` | `true` for the single best case |

Cases are returned sorted by `argument_fit_score` descending.

### `generate_rera`

Takes the scored cases and generates:

| Output field | Description |
|---|---|
| `re_paragraph` | Rule Explanation — synthesizes the rule from the top 2–3 cases using the court's language, with inline Bluebook citations |
| `ra_paragraph` | Rule Application — applies the rule to your client's facts, draws factual analogies, flags 1–2 weaknesses |
| `recommended_lead_case` | The single strongest case to lead with |
| `citation_list` | All citations used |

## Writing rules the agent follows

- Active voice in every sentence
- No hedging ("arguably", "it could be argued", "may potentially")
- Uses the court's own language for the rule — never paraphrases
- Does not introduce new cases in the RA paragraph
- Tailors formality to the specified audience (judge, jury, or memo)

## Example prompts

- *"Find cases on fraudulent misrepresentation in the 5th Circuit and draft RERA paragraphs for my breach of contract claim."*
- *"Extract the rule statement from [case name] and score it against these client facts: [facts]."*
- *"Draft RE and RA for a 12(b)(6) motion to dismiss, jurisdiction: SDNY, audience: judge."*

## Inputs you can provide

| Input | Required | Description |
|---|---|---|
| Cases | Yes | From a prior `searchCaseLaw` call, or paste case names and citations |
| Client facts | Yes | The facts of your client's case — used to score rule fit |
| Legal argument | Yes | The specific element being supported (e.g., "breach of fiduciary duty") |
| Jurisdiction | Optional | Circuit, district, or state — defaults to Federal |
| Audience | Optional | `judge`, `jury`, or `memo` — tailors formality |
