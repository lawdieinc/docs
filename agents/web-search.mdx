## What it does

The web search agent uses Tavily to search the open web and return current, relevant results. It's useful for anything that falls outside court databases and USPTO — regulatory guidance, news coverage, company background checks, and secondary legal sources.

## Example prompts

- *"What are the latest FTC guidelines on non-compete agreements?"*
- *"Find recent news coverage of the Johnson v. Smith antitrust case."*
- *"What is the current SEC enforcement position on crypto securities?"*
- *"Look up the background and ownership of Apex Holdings LLC."*
- *"Find any public information about pending litigation involving Verdant Corp."*

## When to use web search vs. legal research

| Use case | Recommended agent |
|----------|------------------|
| Finding court opinions and case law | [Legal Research](/agents/legal-research) |
| Current regulatory news and guidance | Web Search |
| Company and party background | Web Search |
| Patent and IP searches | [Patent Search](/agents/patent-search) |
| Common law trademark usage | Web Search |
| General factual research | Web Search |

## Limitations

Web search returns publicly available information as of the search date. It does not access paywalled legal databases (Westlaw, LexisNexis) or sealed court documents. For authoritative case law, always use the Legal Research agent.
